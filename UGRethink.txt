I want to revisit what we can safely extract from Ultimate guitar pages and how it should be presented to the user.
The obvious info are the chords, the lyrics, and how these are linked.
If time signature is present on the page we cannot use it to split up the lyrics. we can only display this info in region 1.
The only thing we can say for sure are the lyrics that are sung for any given chord.
If chords are given without lyrics we can only say there are no lyrics.
There is info about intro's, verses, choruses, bridges, outros and possibly others.  This is useful and could be put together into a virtual "voice" called "sections". 
Do we have any existing mechanisms to allow quick navigation between sections? It is a little clumsy to have the user solo sections and navigate back in the note region, and then unsolo sections again.  Could we navigate with alt left and right arrows?  Or introduce a brand new keystroke specific to UG scores to navigate by section?  Might translate to guitar pro files also, or music XML which contains lyrics and also denoates sections.
What strumming info is there?  There surely must be more than one strumming pattern per song very frequently.  I would guess that many songs have more than one strumming pattern. Is this born out in the examples listed below?
If there is, is there any indication of when one pattern or another is played?
Currently the strumming is played, but in practice, it is almost impossible to work out the strumming pattern from this audio.
Can we have a dialogue that displays the strumming pattern which the user can navigate? e.g. a table with two rows. top row is time position, second row is up, down, nothing.
With all this in mind, take a look at the examples and draw up a plan for how best to get the most out of a UG page, and how the info should be surfaced, navigated, and saved.
BTW, if someone saves a UG page, does this come up in the recents list?
And minor point, can you make the recents list show the filename first, followed by the path in brackets.
